# Lane T: vite 5 -> 8 and vitest 2 -> 4 upgrade - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move `web/` from vite 5.4.21 / vitest 2.1.9 / `@vitejs/plugin-react` 4.7.0 to vite 8 / vitest 4 / plugin-react 6, clearing the five dev-tooling audit advisories, with the unit-test collection count, the production bundle and the browser harness all measured before and after.

**Tech Stack:** node + npm (web/), vitest, vite, TypeScript (`tsc -b`), Playwright (`make test-e2e`), Go only as the consumer of the embedded bundle (no Go source is edited).

- [ ] **Step 9: Write the lockfile platform-variant checker to the scratchpad**

Save this as `lockcheck.mjs` **in your scratchpad directory, not in the worktree**:

```js
import { readFileSync } from 'node:fs'

const lock = JSON.parse(readFileSync(process.argv[2] ?? 'package-lock.json', 'utf8'))
const pkgs = lock.packages

// npm records EVERY optional dependency of every package in the lock, whatever
// platform generated it. A name declared as an optionalDependency but absent
// from `packages` is the shape that makes `npm ci` fail on a platform other
// than the one the lock was generated on.
const missing = []
for (const [parent, meta] of Object.entries(pkgs)) {
  for (const name of Object.keys(meta.optionalDependencies ?? {})) {
    const nested = `${parent}/node_modules/${name}`
    const top = `node_modules/${name}`
    if (!(nested in pkgs) && !(top in pkgs)) missing.push(`${parent || '<root>'} -> ${name}`)
  }
}

const platform = /(linux|darwin|win32|android|freebsd|openbsd|netbsd|sunos|aix)[-.]/
const platformKeys = Object.keys(pkgs).filter((k) => platform.test(k)).sort()
const linuxX64 = platformKeys.filter((k) => k.includes('linux-x64'))

console.log(`lock packages: ${Object.keys(pkgs).length}`)
console.log(`platform-variant entries: ${platformKeys.length}`)
console.log(`linux-x64 entries (${linuxX64.length}):`)
for (const k of linuxX64) console.log(`  ${k}`)
console.log(`missing optional deps (${missing.length}):`)
for (const m of missing) console.log(`  ${m}`)
```
