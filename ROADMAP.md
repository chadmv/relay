# Roadmap

> Generated by /roadmap on 2026-08-21 (third refresh today), closing ingest-log suppression - slice 2
> of the four-item silent-drop cluster, and the second of the four to land. Open count holds at 90 for
> the second refresh running: one closed, one filed. Three sibling items were amended rather than
> duplicated. Suggested backlog actions is empty and omitted.
> Source of truth is docs/backlog/ - edit items there, then re-run /roadmap. Manual edits may be
> overwritten.

Relay is a distributed task/render-farm orchestrator: three Go binaries (relay-server =
HTTP + gRPC + scheduler with an embedded React/Vite SPA; relay-agent worker that holds one gRPC
stream and runs each task as a subprocess; the relay CLI), plus an MCP server and a Perforce
source-provider. Hardening is complete - the 2026-06-10 review's findings are closed and the
seven cross-cutting invariants in CLAUDE.md are enforced and well-tested. They are written in
backend terms but hold across the stack: the generation-ordering rule was rediscovered as a
frontend bug, so `web/` changes are in scope for them too.

The active phase is the embedded web SPA build-out, governed by the `design_handoff_relay_holo`
"Holo" direction (the hi-fi `hifi3-holo-pages.jsx` layer is authoritative; `reference/` is
structure-only). The relayout is done and every surface sits on the shared
`web/src/components/holo` primitives, so what remains is net-new surfaces and backend depth, not
styling. Two rules govern the work: omit data the backend cannot supply rather than fabricating
it, and file the enabler instead; and extract a shared primitive before its third consumer.
Remaining, in rough order: the jobs filter/lane/timeline views, the job-actions wiring, and the
backend enrichers and small endpoints those need. The web-enabler endpoint trio is now fully
shipped, so no backend item currently blocks a frontend one. MCP, agent-runtime and store/schema
items fill in behind. Accessibility and shared-primitive debt is the most reprioritized category
in recent refreshes.
